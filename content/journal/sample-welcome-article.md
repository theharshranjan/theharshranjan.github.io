This article was created entirely from the admin panel — no code was touched, and it now uses the exact same design as your other Journal articles: breadcrumb, banner, byline, tag pills, and author card included.

## How it works

A contributor logs into the admin panel, fills in the title, description, image, tags, author details, and body text, then clicks Publish. This exact page, plus its card on the Journal listing, is generated automatically in the same visual style as the rest of the site.

> Everything renders using Samarpan's existing fonts, colors, and article layout automatically — no design work needed per article.

## What you can do in the body

Use **bold**, *italics*, and [links](https://thesamarpan.co.in). Add section headings with `##`. Make bullet lists. Add a blockquote for a pull-quote style callout, just like the one above.

Once you're comfortable with how this looks, delete this sample article from the admin panel.
